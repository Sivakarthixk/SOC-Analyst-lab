# SOC Analyst Home Lab 🛡️

Hands-on cybersecurity project focused on developing practical Security Operations Center (SOC) skills through network analysis, security monitoring, threat detection, investigation, and incident response.

## 🎯 Project Objectives

* Develop practical SOC Analyst skills
* Analyze network traffic
* Investigate security alerts
* Identify suspicious activities
* Perform basic security analysis
* Document investigation findings
* Practice incident response

## 🛠️ Tools Used

* Wireshark
* Nmap
* Kali Linux
* Burp Suite
* Windows
* Windows Server

## 🔍 Investigations

### 01 — Network Traffic Analysis

Analyzed captured network traffic using Wireshark, including DNS and TCP communication, source and destination IP addresses, protocols, and network ports.
